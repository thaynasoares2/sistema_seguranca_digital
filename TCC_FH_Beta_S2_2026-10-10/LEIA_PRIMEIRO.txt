TCC FH — PACOTE COMPLETO DA BETA S2 — 2026-10-10

Fernanda, este pacote reúne o sistema e toda a documentação disponível do TCC.

1. EXTRAIA O ZIP INTEIRO antes de executar qualquer arquivo.
   Guarde a pasta em Documentos ou Projetos. Não execute de dentro do ZIP.
2. O computador precisa ter Python instalado. Preferência: Python 3.12 ou 3.13.
   O funcionamento foi testado em Linux com Python 3.13.
   No Windows, a instalação do Python deve disponibilizar o comando py ou python.
3. WINDOWS: abra instalar.bat. LINUX/macOS: abra um terminal nesta pasta
   e execute sh instalar.sh.
4. Escolha e confirme uma senha de pelo menos 12 caracteres quando solicitada.
   O instalador cria um banco novo, importa os 31 controles e carrega a Alpha fictícia.
   As bibliotecas estão incluídas; essa etapa não precisa acessar a internet.
5. WINDOWS: abra iniciar.bat. LINUX/macOS: execute sh iniciar.sh.
6. Abra http://127.0.0.1:8000/ e entre como alpha_gestor usando a senha escolhida.
   Outros usuários: alpha_tecnico, alpha_operacional e alpha_conselheiro.
7. Mantenha o terminal aberto enquanto usa o sistema. Ctrl+C encerra o servidor.

SUPORTE À INSTALAÇÃO
- “py/python não reconhecido”: instale Python ou abra um terminal em que ele esteja disponível.
- “No module named venv/ensurepip”: no Linux, instale o suporte a venv da versão do Python usada.
- Porta 8000 ocupada: encerre outra instância do sistema antes de iniciar.
- A senha não aparece enquanto você digita; isso é esperado.
- Para criar conta administrativa: após instalar, execute no Windows
  .venv\Scripts\python.exe sistema\manage.py createsuperuser
  ou no Linux/macOS .venv/bin/python sistema/manage.py createsuperuser.
- Para conferir a instalação com os testes: python instalar.py --verificar.
- Se esquecer a senha: após instalar, execute no Windows
  .venv\Scripts\python.exe sistema\manage.py changepassword alpha_gestor
  ou no Linux/macOS .venv/bin/python sistema/manage.py changepassword alpha_gestor.
- O endereço 127.0.0.1 funciona somente na máquina que executa o sistema.
  Este pacote é para demonstração local; publicação em servidor exige configuração própria.
